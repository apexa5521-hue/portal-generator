# مولّد صفحات الهبوط الموحدة

لوحة إدارة تُنشئ صفحات تجمع عدة منصات في بطاقات أنيقة، وتُصدَّر كل صفحة برابط واحد قصير: `.../?p=hr`

- **الواجهة:** GitHub Pages (HTML/CSS/JS بدون أدوات بناء)
- **التخزين والإدارة:** Google Sheets + Google Apps Script
- **الملفات:** `index.html` صفحة المستفيد، `admin.html` لوحة الإدارة، `Code.gs` الخادم، `config.js` الإعدادات

> بدون ضبط `API_URL` يعمل النظام بوضع تجريبي يحفظ في متصفحك فقط (للتجربة). صفحة العرض التجريبية: `?p=demo`

## خطوات التشغيل

### 1) إنشاء الخادم (مرة واحدة)
1. أنشئ Google Sheet جديدًا فارغًا (اسمه أي شيء).
2. من القائمة: **Extensions ← Apps Script**.
3. احذف المحتوى والصق محتوى `Code.gs`، ثم احفظ.
4. شغّل الدالة **`setup`** (وافق على الصلاحيات). تُنشئ الورقتين `Pages` و`Cards` وتولّد **رمز دخول من 6 أرقام**.
5. افتح **Execution log** وانسخ الرمز. لتغييره: عدّل `NEW_PIN` داخل `setAdminPin` وشغّلها.
6. **Deploy ← New deployment ← Web app**: *Execute as: Me*، *Who has access: Anyone*. انسخ رابط الـ`/exec`.

### 2) ربط الواجهة
ضع الرابط في `config.js`:
```js
API_URL: 'https://script.google.com/macros/s/XXXX/exec',
```

### 3) تفعيل GitHub Pages
في الريبو: **Settings ← Pages ← Deploy from a branch ← main / root**.

بعدها: لوحة الإدارة على `.../admin.html`.

## الاستخدام
1. ادخل لوحة الإدارة برمز الدخول.
2. **صفحة جديدة**: العنوان، الجهة المستفيدة (مثل «للموارد البشرية»)، اللون، عدد البطاقات.
3. لكل بطاقة: اسم المنصة، الهدف، رابط صفحة تسجيل الدخول، أيقونة أو شعار.
4. **حفظ**، ثم انسخ الرابط الموحد (أو استخدم QR) وأرسله للمستفيد.

## ملاحظات أمنية
- رابط الصفحة عام لمن يملكه؛ الأنظمة نفسها محمية بتسجيل دخولها. الروابط داخل البطاقات تظهر لمن يفحص الصفحة تقنيًا.
- الرمز يُحفظ في Script Properties، وبعد 5 محاولات خاطئة يُقفل الدخول 10 دقائق.
- لا تشارك رابط الـ Sheet ولا رمز الدخول. الصفحات محجوبة عن محركات البحث (`noindex`).
- بعد تعديل `Code.gs` أعد النشر: **Deploy ← Manage deployments ← Edit ← New version**.
